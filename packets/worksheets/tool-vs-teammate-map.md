# Worksheet: The Tool vs Teammate Map

Every piece of work you might hand to an agent sits somewhere on a spectrum from Tool to Teammate.

| Position | 1 · Tool | 2 | 3 | 4 · Teammate | H · Human only |
| - | - | - | - | - | - |
| **What it means** | Executes on command; zero discretion | Drafts; a human reviews and sends every output | Acts alone inside hard caps; humans review samples and exceptions | Owns an outcome; plans multi-step work; uses judgment; escalates by rule | Off the spectrum: the call stays human. Agents brief the decision; a named person makes it |

At position 1 the human supplies all the judgment. At position 4 the agent supplies most of it, inside a boundary the humans designed. H is the honest fifth answer: some calls are never delegated, and knowing which ones is executive work.

## Placement criteria

Score the work, not the technology. Four questions place any item:

| Criterion | The question |
| - | - |
| Discretion | How much judgment does the work actually require, case by case? |
| Reversibility | If it goes wrong once, can you undo it? At what cost? |
| Blast radius | How much damage can one bad run do before anyone notices: dollars, customers, trust? |
| Oversight | What review actually exists today: every output, samples, or nothing? |

Low discretion, easy reversal, small blast radius, real oversight: the item can sit further right than it does today. High discretion or a wide blast radius does not mean never delegate. It means the move requires a boundary or a human gate, and you must be able to name it.
