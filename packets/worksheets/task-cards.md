# The Department Task Cards

Three baseline tasks per department. This is your agent's first day of real work: use the copy button on each task, paste it to your agent one at a time, watch it work, and judge the output like the executive you are. The bar for each task: is it true (did a tool confirm it), is it useful (could you act on it), and would you put your name on it.

Two of three passing is a normal first build. Three of three on the first try usually means you have not looked closely enough.

Running The Whole Council solo? Start with the Customer Ops card: it produces the most visible work fastest. Then take any other card that interests you.

## Customer Ops

1. Test the agent we made by running this prompt: "Pull the five oldest open tickets from FloatDesk and reply to each honestly. No invented ship dates: if the system cannot confirm a date, the reply says so and gives the customer their real options."
2. Test the agent we made by running this prompt: "A customer asks where order ORD-104501 is. Find the order, find its status, and draft the reply you would actually send."
3. Test the agent we made by running this prompt: "Report the queue: how many tickets are open, how old is the oldest, and what single change would help most by tomorrow morning."
